# Dasbor Pemantauan Triple Burden of Malnutrition NTT 2045

Mockup dasbor riset PRIS RUPA Future Society 2026 (FKM UI dan OR IPSH BRIN):
"Membaca Masa Depan Gizi NTT: Lintasan Triple Burden of Malnutrition 2045 dari Big Data dan Suara Warga".

**Status: mockup.** Semua angka, kelompok kabupaten, dan posisi desa adalah ilustrasi untuk membahas tampilan, bukan data atau hasil riset. Daftar indikator final dan batas peringatan ditetapkan pada FGD II (Mei 2027).

## Halaman
1. Ringkasan indikator inti tahunan
2. Peta dan lintasan per kabupaten/kota
3. Kelompok kabupaten menurut pola perubahan (kml)
4. Empat skenario 2045 dan penanda arah
5. Suara warga dari 6 desa di 3 lokasi
6. Metadata indikator dan data agregat

## Dokumentasi
- Alur pengolahan data per menu (flowchart): [docs/alur-pengolahan.md](docs/alur-pengolahan.md), draf sedang direvisi

## Prinsip data
- Hanya data agregat tingkat kabupaten/kota dan desa.
- Tidak ada data mikro maupun identitas informan (UU 27/2022 tentang Pelindungan Data Pribadi dan protokol etik).
